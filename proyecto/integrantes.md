# MediPlus - Sistema de Gestión de Citas y Consulta Externa

## Descripción del Proyecto
Sistema web integral para la gestión de citas médicas, historias clínicas electrónicas y procesos asistenciales del Centro de Salud Universitario San Rafael, atendiendo a 12,000 afiliados de la comunidad universitaria.
